# NotepadXX Parity Matrix — File Menu, Edit Menu, Tab Bar & Document Management

Source of truth for command IDs and menu structure: `notepad-plus-plus/notepad-plus-plus` @ `master` (commit `67e755f`, 2026-08-17) —
`PowerEditor/src/menuCmdID.h`, `PowerEditor/src/Notepad_plus.rc`, `PowerEditor/src/Parameters.cpp` (default shortcut tables
`winKeyDefs[]` / `scintKeyDefs[]`), `PowerEditor/src/NppNotification.cpp` (default tab-bar context menu array), and
`PowerEditor/src/lastRecentFileList.cpp` (Recent Files submenu). Behavior text cross-checked against
https://npp-user-manual.org/docs/files/, /docs/editing/, /docs/user-interface/.

Columns: **ID** (Notepad++ constant) · **Menu path** · **Command** · **Default Windows shortcut** · **Behavior** ·
**macOS equivalent/notes** · **Complexity** (S/M/L/XL, Swift/AppKit rewrite effort) · **Tier** (E=Essential, I=Important, N=Nice-to-have)

---

## Coverage notes

- **Excluded as not currently user-visible:** `IDM_EDIT_TRANSPOSE_LINE` (`IDM_EDIT+11`) has a command-ID reservation and a switch-case handler in `NppCommands.cpp`, but is wired into no menu (`.rc`) and no default shortcut in `Parameters.cpp` in the current source — it is dead/legacy and was excluded from the "every user-visible command" count per the verification pass against the `.rc` file, rather than trusted from the header name alone.
- **Excluded as out of File/Edit/tab-management scope:** `IDM_EDIT_RTL` / `IDM_EDIT_LTR` ("Text Direction RTL/LTR") share the `IDM_EDIT_*` ID prefix by numbering convention only — they are actually menu items under the Language menu per `Notepad_plus.rc` (line 866-867), not the Edit menu, and were left out accordingly. The Format-menu encoding submenu (ANSI/UTF-8/UTF-16/codepages) was also left out as it's a separate menu, except for the three EOL-conversion items which the Edit menu itself hosts (`IDM_FORMAT_TODOS/TOUNIX/TOMAC`) and are included in §B.
- Search-menu, View-menu (beyond tab management), Language-menu, and Settings-menu commands are out of this document's scope by the original brief and were intentionally omitted, including bookmark commands, marker/style-to-clipboard commands, and folding commands, all of which live under `IDM_SEARCH`/`IDM_VIEW` outside the tab-management subset called out above.
